# Benchmark results data directory

This directory contains raw benchmark data in JSON and CSV formats.

## Files

- `comparison.json` - Aggregated comparison data for all frameworks
- Individual framework results (generated by benchmark runs)

## Data Format

Each benchmark result file contains:

```json
{
  "framework": "framework_name",
  "timestamp": "ISO8601 timestamp",
  "config": {
    "duration": 600,
    "concurrency": 100,
    "model": "model_name",
    "input_tokens": 512,
    "output_tokens": 128
  },
  "summary": {
    "total_requests": 50000,
    "successful_requests": 49950,
    "failed_requests": 50,
    "duration_seconds": 600.0,
    "requests_per_second": 83.25
  },
  "latency": {
    "mean_ms": 35.2,
    "median_ms": 32.1,
    "p50_ms": 32.1,
    "p95_ms": 58.3,
    "p99_ms": 75.6,
    "min_ms": 15.2,
    "max_ms": 250.3,
    "stdev_ms": 12.4
  },
  "throughput": {
    "tokens_per_second": 1280,
    "requests_per_second": 83.25
  }
}
```

## Usage

These data files can be used with the visualization scripts:

```bash
cd ../../scripts
python generate-charts.py --input ../benchmarks/data/comparison.json --output ../benchmarks/visualizations/
```
